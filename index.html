Setup In Your Salesforce Developer Org (2 Minutes)

1. In Salesforce Setup, go to Remote Site Settings and whitelist https://theaters-eric-portable-recipient.trycloudflare.com.
2. Open Developer Console, create an Apex class named BiteShareCallout, and an Apex Trigger on Food_Donation__c.

// Apex Trigger on Food_Donation__c trigger BiteShareWebhookTrigger on Food_Donation__c (after insert, after update) { for (Food_Donation__c fd : Trigger.new) { BiteShareCallout.syncDonationToSAP( fd.Id, fd.Food_Type__c, fd.Quantity__c, fd.City__c, fd.Usable_Until__c, fd.Status__c ); } }
